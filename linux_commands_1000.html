Reading files

Read long files without losing your place.

Use less for safe, page-by-page reading. It does not modify the file.

Use less

less results.log
Key Action
Space / f One page forward.
b One page backward.
g / G Beginning / end of the file.
10g Jump to line 10.
/word , n Search, then next result.
q Quit back to the terminal.
less +G file.txt opens at the end. less +10 file.txt starts near line 10.

Read selected lines and logs

head -n 20 file.txt

First 20 lines.

tail -n 20 file.txt

Last 20 lines.

tail -f output.log

Watch a log while it grows; stop with Ctrl+C .

sed -n '10,20p' file.txt

Only lines 10–20.

grep -n 'error' output.log

Find text and show the line number.

Nano and Emacs

Edit, save, navigate, and exit from a terminal.

Ctrl means hold Control; Alt may appear as M in Emacs documents.

Nano: simplest terminal editor

nano notes.txt
Key Action
Ctrl+O , Enter Save the file.
Ctrl+X Exit; Nano asks whether to save unsaved work.
Ctrl+_ , 10 Jump to line 10.
Ctrl+V / Ctrl+Y Page down / page up.
Ctrl+K Cut the current line; press repeatedly to delete line by line.
Ctrl+U Paste cut text.
Erase all text: Ctrl+_ → 1 , Ctrl+^ to mark, Alt+/ to go to the end, then Ctrl+K . Save using Ctrl+O .

Emacs inside the terminal

emacs -nw job.slurm

-nw runs Emacs without a graphical window — ideal over SSH.

Key Action
Ctrl+x Ctrl+s Save.
Ctrl+x Ctrl+c Exit.
Alt+< / Alt+> Beginning / end of file.
Alt+g g , 10 Go to line 10.
Ctrl+v / Alt+v Page down / page up.
Ctrl+k Delete to line end; at its start, removes the whole line.
Ctrl+x Ctrl+f Open another file.
Delete all: Alt+< , Ctrl+Space , Alt+> , Ctrl+w . Undo with Ctrl+/ .

Parallel terminals

Use tmux without killing your work.

tmux is especially useful on a server: detach, close SSH, and reconnect later.

Start and reconnect

tmux new -s research

Create a named session.

tmux ls

See your sessions.

tmux attach -t research

Reconnect later.

Ctrl+b d

Detach safely without ending your programs.

Split panes

Inside tmux Action
Ctrl+b % Vertical split: left and right.
Ctrl+b " Horizontal split: top and bottom.
Ctrl+b + arrow Move between panes.
Ctrl+b x Close only the current pane.

HPC jobs and resources

Submit work, check the queue, and control processes.

These examples use the common Slurm scheduler. Check your own cluster’s partition names and limits.

Submit a Slurm job 

#!/bin/bash
#SBATCH --job-name=training
#SBATCH --time=02:00:00
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --output=logs/%x-%j.out

module load python
python train.py
mkdir -p logs sbatch job.slurm

Keep the returned job ID.

Queue and status

squeue -u $USER

Your pending and running jobs.

sinfo

Cluster partitions and availability.

scontrol show job JOBID

Detailed job status.

tail -f logs/training-JOBID.out

Live job output; stop watching with Ctrl+C .

sacct -j JOBID

Completed job accounting; seff JOBID shows efficiency if installed.

Stop and inspect work

scancel JOBID

Cancel a submitted Slurm job.

ps aux | less

List processes; pgrep -af python finds by name.

top or htop

Interactive CPU and memory use; press q to exit.

kill PID

Ask a local process to stop. Use kill -9 PID only as a last resort.

Memory, disk, and GPU

free -h

System RAM usage.

df -h

Free disk space.

du -sh results

Size of one folder.

nvidia-smi

NVIDIA GPU memory and processes, when available.
